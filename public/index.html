Overview

Are You an Acktual Local?

One island day on Nantucket. Move across the real road network, answer questions at a difficulty you choose, and make the last boat home. The table gets a winner; every player gets an island identity.

Four decisions that define the design

Scoring
Two ledgers

Island Score picks the winner. Knowledge alone picks your identity.

Questions
You pick the difficulty

Visitor, Regular or Local, declared before the question is read.

Movement
No dice

Walk (deeper choice), bike (farther), or ride the Wave.

Catch-up
The Last Boat

+2 for making the ferry. Visitors take it, locals keep exploring.

Design

Scoring & identity

A visitor can have a great game, win, and still honestly be a Summer Person.

rules/score.tstwo ledgers
export const islandScore = (p) =>
    sum(LENSES.map(l => Math.min(p.ticks[l], 3)))  // capped
  + p.stamped.size                           // +1 per place
  + 4 * p.regionsDone.size                   // 3 of 4 places
  + p.harbor                                 // +5 / +1
  + 2 * p.challenges
  + (p.madeLastBoat ? 2 : 0);

export function identity(p) {
  const k = sum(Object.values(p.ticks));      // uncapped
  const b = LENSES.filter(l => p.ticks[l] >= 3).length;
  if (k >= 24 && b >= 3) return 'Acktual Local';
  if (k >= 18 && b >= 2) return 'Year-Rounder';
  if (k >= 11 && b >= 1) return 'Wash-Ashore';
  if (k >= 6)            return 'Summer Person';
  return 'Day Tripper';
}

Build

Engineering

Rules are written once as code. Rulebook, print files, simulator and digital playtests all read the same source.

rules/reducer.tspure · replayable from a log
type Action =
  | { type: 'MOVE'; move: Move }
  | { type: 'DECLARE'; tier: 1 | 2 | 3 }
  | { type: 'RESOLVE'; correct: boolean }
  | { type: 'HARBOR'; guesses: number[] }
  | { type: 'BOAT'; player: number; board: boolean };

export function step(s: GameState, a: Action): GameState {
  switch (a.type) {
    case 'MOVE':
      assertLegal(s, a.move, activeAlmanac(s)); // budget, fog, nor'easter
      return arrive(s, a.move);                // stamp + region
    case 'DECLARE': return { ...s, phase: 'resolve', declared: a.tier };
    case 'RESOLVE': return a.correct ? tick(s, lensOf(s.drawn), s.declared) : advance(s);
    case 'HARBOR':  return awardClosest(s, a.guesses, [5, 1]);
    case 'BOAT':    return setBoat(s, a.player, a.board);
  }
}

const BAND = { 1: [.70, .95], 2: [.35, .65], 3: [.10, .35] };

for (const q of questions) {
  const { n, correct } = stats[q.id];
  if (n < 12) continue;
  const p = correct / n, [lo, hi] = BAND[q.tier];
  if (p < lo) flag(q, 'too hard', p);
  else if (p > hi) flag(q, 'too easy', p);
}
