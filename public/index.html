01 — Design Philosophy

Most location-themed games fail because the location is a skin, not a structure. Swap "Nantucket" for "Martha's Vineyard" and the game works identically — which means neither version works well. The core principle here: every mechanical decision should be derived from something true about Nantucket.

The board follows the island's actual coastal geography, not an abstract loop. The four knowledge dimensions (History, Culture, Nature, Local Life) map to how people actually experience the island — tourists learn Nature first (beaches), then Culture (restaurants, events), then History (museums), then Local Life (off-season rhythms, slang, unwritten rules). The difficulty tiers mirror a real relationship arc with a place: Visitor → Regular → Local.

The game shouldn't teach Nantucket like a textbook. It should teach it like a friend who's been coming for twenty years — through stories, arguments about the best beach, and the occasional "wait, you didn't know that?"

🗺️
Place-Native Mechanics
The geography dictates the board. The culture dictates the encounters. The social fabric dictates the scoring. Nothing is interchangeable.
🪞
Identity as Outcome
"Summer Regular" should feel personally true, not arbitrarily assigned. Categories describe a relationship with a place, not a score bracket.
📐
Engineered Accessibility
A first-time visitor should score 40-70 points. A lifelong local should score 120-160. Both should have fun. That's a calibration problem, not a philosophy problem.

Why this matters for playtesting: Every rules ambiguity I've seen in board game development comes from undefined state transitions. "What happens if I land on a fork AND there's an encounter?" — with this state machine, the answer is always deterministic. MOVE checks for fork first, resolves it, then checks for encounter.

Expected Value Analysis

Pure EV says Regular and Local are equivalent (both 5.0), while Visitor is strictly worse (4.0). But this misses two critical factors:

Streak bonus shifts the equilibrium. A player on a 3-question streak earns +3 bonus per correct answer. At that point, the Visitor tier's EV becomes 5+3 × 80% = 6.4 while Local becomes 20+3 × 25% = 5.75. A streak makes safe play more valuable — which creates an interesting dynamic where leading players become more conservative (protecting streaks) while trailing players take bigger risks.

Dimension thresholds create situational tier preferences. A player at 28/30 in History who draws a History question should pick Visitor — they just need 5 points to cross the threshold. A player at 12/30 in Nature needs to swing big with Local-tier Nature questions. The category algorithm makes the "correct" tier contextual, not fixed.

Design validation: When the "right" choice depends on game state (your score, your streak, which dimension you need), the mechanic is working. If one tier were always optimal, it would be a false choice — remove it and save the player the decision. The math here confirms all three tiers have situations where they're the correct play.

Location-Encounter Binding

Each board location is tagged with a primary dimension. The encounter card drawn at that location is weighted 70% toward the location's dimension and 30% random. This means a player visiting the Whaling Museum has a 70% chance of drawing a History question — but a 30% chance of Culture, Nature, or Local Life. The weighting creates thematic consistency without predictability.

08 — Category Algorithm

The category assignment uses a dual-gate system: total score AND dimension breadth. This prevents a player who knows only History from reaching "Acktual Local" — because a real local knows the island broadly.

Algorithm (Pseudocode)

function assignCategory(total, dims): min_dim = min(dims.history, dims.culture, dims.nature, dims.local) dims_above_25 = count(d for d in dims if d >= 25) if total >= 140 and min_dim >= 25: return "Acktual Local" // Broad + deep elif total >= 100 and dims_above_25 >= 3: return "Seasoned Islander" // Strong breadth elif total >= 70 and dims_above_25 >= 2: return "Summer Regular" // Building knowledge elif total >= 40: return "Weekend Visitor" // Knows the basics else: return "Day Tripper" // Just arriving

15% luck ensures a newcomer can occasionally beat an expert (die rolls + Island Moments). 20% social means the Challenge cards — where the group judges your answer — add unpredictability that pure knowledge can't control. These two pillars are what prevent the game from feeling like a test.

15 — Expansion Architecture

The card-based encounter system is designed for expansion without rule changes. New content slots into existing decks — the game engine doesn't change.

ExpansionWhat It AddsMechanical Impact
Seasonal Pack40 new questions about Stroll, Daffodil Festival, summer vs winter island lifeShuffle into existing trivia decks. No rule changes.
Deep History Pack40 questions on Wampanoag history, whaling era details, Civil War Nantucket, ProhibitionReplaces or supplements History dimension cards. Optional "historian" variant rules.
Insider Pack40 questions only year-round residents would know. Raises the bar for "Acktual Local."Adds a 4th difficulty tier (🟣 Insider = 30 pts, ~15% correct rate). New category: "True Islander."
Location SeriesMartha's Vineyard, Cape Cod, Hamptons, Key West — same framework, new contentNew board, new cards. Same rules, same scoring, same categories. Franchise potential.
The franchise angle is real. "Are You an Acktual Local?" works as a format, not just a single product. Every coastal town, college town, or destination city has a community that would play this game. The mechanical framework — location-based board, tiered trivia, dimension scoring, identity categories — transfers to any place with enough local knowledge to fill 160 cards. Build one, and you've built the template for many.
